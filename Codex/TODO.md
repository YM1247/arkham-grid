# Arkham Grid 開發索引

本文件只追蹤執行狀態。完整目標、交付成果、驗收標準與依賴請看 [`docs/PROJECT_ROADMAP.md`](../docs/PROJECT_ROADMAP.md)；需要玩家決定的內容請看 [`docs/OPEN_QUESTIONS.md`](../docs/OPEN_QUESTIONS.md)。

執行規則：

- 未回答的 Open Question 不得由開發者自行選擇答案。
- 可以先完成不依賴答案的資料介面、測試與架構準備。
- 每完成一項工作，同步更新本文件與 `docs/DEVELOPMENT_LOG.md`。
- 數值改動同步更新 `docs/BALANCE_LOG.md`。

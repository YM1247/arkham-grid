# 宏觀遊戲設計與世界觀設定 (Macro Game Design & Worldview)

> 本文件保留早期宏觀提案。局外養成、永久數值與職業仍受 `META-001` 至 `META-004` 約束，玩家確認前不視為已定規格；現行細節以 `docs/OPEN_QUESTIONS.md` 與 `docs/PROJECT_ROADMAP.md` 為準。

## 🌌 1. 遊戲背景與核心主題
* **世界觀風格**：克蘇魯神話 (Cthulhu Mythos) 與暗黑奇幻。
* **氛圍定調**：絕望、瘋狂、不可名狀的恐懼、資源匱乏。
* **核心體驗**：在理智崩潰的邊緣，利用有限的空間與資源進行拼圖式戰鬥，從隨機生成的深淵中尋求生機。

## 🔄 2. 核心遊戲迴圈 (The Roguelike Loop)
遊戲已建立「單局挑戰 (Run-based)」核心迴圈；是否納入「局外養成 (Meta-progression)」與其影響程度仍待 `META-001` 至 `META-004` 決定。

### A. 局內迴圈 (In-Run Loop)
1. **節點探索 (Map Navigation)**：玩家在隨機生成的分支路線地圖上推進（類似《殺戮尖塔》）。
2. **戰鬥遭遇 (Grid Combat)**：進入 8x8 棋盤的方塊放置戰鬥。
3. **戰利品結算 (Looting)**：戰鬥勝利後，三選一獲得新裝備（武器/裝備/祈禱/詛咒）或特殊形狀的新方塊。
4. **資源消耗與管理**：推進過程中需持續關注 HP 與理智值 (Sanity)。

### B. 局外迴圈候選案 (Out-of-Run Meta Loop)
1. **結算與死亡**：單局遊戲通關或角色死亡後，根據推進深度與成就，獲得「局外代幣/異界碎片」。
2. **大廳養成 (Hub Hub/Meta-Progression)**：在局外基地消耗代幣，進行永久性升級。
3. **重新出發**：帶著新的永久增益或解鎖的新解鎖池，開始下一輪全新的隨機冒險。

## ⚙️ 3. 關鍵遊戲系統設計 (Key Systems)

### 3.1 雙重生存指標：生命 (HP) 與理智 (Sanity)
* **生命值 (HP)**：歸零時角色死亡，該局遊戲結束。
* **理智值 (Sanity)**：本作的核心特色資源。
  * 遭遇特定怪物、使用強大但具副作用的「詛咒 (Curse)」裝備時會消耗。
  * 理智值過低會觸發「瘋狂狀態」，可能導致：方塊形狀扭曲變異、棋盤隨機出現不可放置的障礙物、或幻覺干擾。

### 3.2 裝備與方塊構建 (Inventory Deckbuilding)
* **方塊池 (Block Pool)**：玩家一開始只有基礎的簡單方塊，隨著進度推進，會獲得佔地更大但更容易觸發多行消除的異形方塊。
* **裝備構築 (Loadout)**：玩家需在 8x8 棋盤的四周配置裝備。如何平衡「橫列物理輸出 (Weapon/Equipment)」與「直行魔法/理智控制 (Prayer/Curse)」是核心策略。

### 3.3 隨機地圖生成 (Procedural Map)
* 地圖由多個節點構成，底層可利用 A* 演算法或其他尋路生成邏輯確保起點至 Boss 房間有合法的隨機路徑。
* **節點類型**：
  * `Combat` (普通戰鬥)
  * `Elite` (菁英戰鬥，掉落稀有方塊/裝備)
  * `Shop` (商店，花費局內金幣購買或升級裝備)
  * `Event` (隨機事件，包含需消耗理智值的抉擇)
  * `Rest` (營地，恢復 HP 或 Sanity)

## 📈 4. 局外養成候選案 (Meta-Progression Mechanics)

以下為早期提案，不是現行已定規格：

1. **基礎能力提升 (Stat Upgrades)**：
   * 提升初始 HP 最大值。
   * 提升初始 Sanity 最大值或抗性。
   * 增加開局時可攜帶的基礎方塊數量。
2. **圖鑑與掉落池擴充 (Unlock Pool)**：
   * 遊戲初始的裝備庫較為基礎。部分強大的克蘇魯遺物、高階祈禱術需在局外解鎖後，才會在未來的「局內商店」或「戰利品」中出現。
3. **初始流派選擇 (Starting Loadouts)**：
   * 解鎖不同的初始職業或套牌（例如：偏向物理輸出的「調查員」、偏向理智控制與魔法的「密教徒」）。

# 遊戲體驗與平衡稽核（2026-09-09）

## 本輪範圍

依 2026-09-08 改變方案與玩家新增方向，本輪完成消除支付預覽、咒文圖例、菁英特殊形狀候選保底、條件式敵人意圖、商店咒文商品、第二個事件、兩組 encounter、10 層地圖，以及以戰鬥時限為核心的 Sanity 壓力。

## 時間壓力規則

- Encounter 強度由敵人總 HP、攻擊、tier 與精神壓力計算。
- 基礎時限為 3 加上強度寬限；地圖每深入 2 層收緊 1 回合，最後限制在 4–7 回合。
- 超過時限後，第 1／2／3… 個逾時回合依序扣除 2／4／6… Sanity。
- 調查員每完成節點的 MP 回復由 35 提高為 50，讓 Sanity 代付保留為緊急手段，而非主要常態消耗。

## 測試方法

`tools/analyze_gameplay.gd` 使用五組固定種子 `424242`、`13579`、`8675309`、`20260908`、`314159`。每個種子執行 8 次完整 Run，共 40 Runs；另對 8 組 encounter 各執行 6 次獨立戰鬥，共 240 場。每場工具上限 12 回合，代理採目前評分最高的合法放置。

## 最終結果

| 指標 | 結果 |
| --- | ---: |
| 完整 Run 通關率 | 77.5%（31/40） |
| HP／Sanity／工具超時失敗 | 5／4／0 |
| 平均結束 HP／Sanity／MP | 53.0／77.7／59.1 |
| 平均戰鬥勝場 | 6.30／7 |
| 平均特殊形狀取得 | 1.20／Run |
| 平均死盤 | 0.12／Run |
| 平均逾時回合 | 3.02／Run |
| 平均時間壓力 Sanity 損失 | 9.50／Run |
| 種子通關率範圍 | 62.5%–87.5% |

8 組獨立 encounter 在 240 場中全數可完成，後段通常需 5–7 回合。完整 Run 同時出現 HP 與 Sanity 失敗，且沒有 12 回合拖延，落在最佳代理 70%–90% 的回歸目標內。

2026-09-13 加入死因分項後重跑相同 40 Runs，結果完全一致。4 次 Sanity 敗北的最後致死來源為咒文代付 3 次、敵人精神攻擊 1 次；時間壓力雖未直接造成最後一擊，仍平均先消耗 9.5 Sanity，因此判讀時必須同時看各來源累積損失與最後致死來源。

## 體驗判讀

- 戰鬥時限現在會讓單純防守與等待好盤面的策略付出可見代價；遞增扣除比固定扣除更能製造「環境使人逐漸發瘋」的壓迫。
- 節點 MP 回復提高後，正常戰鬥較少只因資源枯竭連續代付；玩家仍可在高成本連鎖或不利種子中耗盡 Sanity。
- 10 層路線固定包含 7 場戰鬥，後半段新增兩組敵人搭配，使條件式意圖有更多出場空間。
- 菁英候選保底讓每 Run 平均取得 1.20 個特殊形狀，但不影響特殊形狀進入手牌後的低抽取權重，避免再次出現星點石板壟斷手牌。
- 消除預覽會顯示實際觸發順序、總 MP 與 Sanity 代付，咒文圖例則降低記憶 20 種符號的負擔。

## 後續建議

1. 先做真人測試，特別觀察最低通關種子是否因不可讀的盤面變異，而不是可改善的決策錯誤。
2. 讓回合時限在戰鬥開始時有一次短動畫或文字提示。已於 2026-09-13 完成跨局只顯示一次的資料化文字教學。
3. 追蹤各場「因時間壓力死亡」與「因咒文代付死亡」的分項，不只看 Sanity 失敗總數。已於 2026-09-13 接入正式戰鬥報告、近期 Run 與兩類批次模擬。
4. 商店下一步可加入隨機庫存與特殊形狀商品，但這會改變構築可靠度，實作前需另行評估。

目前沒有新的高影響未決問題；上述第 1–3 項可在既有方向下繼續推進。

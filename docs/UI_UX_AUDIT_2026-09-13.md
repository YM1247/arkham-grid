# UI／操作體驗稽核（2026-09-13）

## 結論

改造前的介面已能驗證規則，但不適合連續遊玩：資訊主要堆在裸露文字與預設按鈕上，戰鬥畫面缺少清楚層級，地圖與結算有大量無效空白，而且拖曳幾乎是唯一盤面操作。Phase 17 本輪已將介面提升為可完整操作的第一版 PC 內部原型，建立統一 Theme、正式 HUD、畫面流程、焦點導覽及鍵盤放置。

## 改造前問題

### P0：直接影響操作

- 方塊只能依賴拖曳；沒有手牌選取、盤面游標、鍵盤放置或明確取消方式。
- 非法放置只讓預覽消失，玩家無法分辨越界、重疊或操作中斷。
- 地圖、獎勵與結算缺少一致的初始焦點，純鍵盤流程不完整。
- 戰鬥資訊散落在右側文字中，AP、時限、HP、Sanity、MP、狀態與敵人意圖無法快速掃讀。

### P1：資訊辨識與節奏

- 敵人資訊由總覽文字與敵人卡重複呈現，資訊擁擠但重點仍不突出。
- 玩家三種資源只有單行文字，難以辨識危險程度與變化。
- 手牌只有形狀，缺少名稱與快捷鍵提示；盤面列行以 `R1/C1` 呈現，增加不必要閱讀負擔。
- 獎勵候選只顯示名稱與 Tier，必須依賴 tooltip 才能比較效果與成本。
- 事件選項的代價、結果與不可選原因雖存在，但按鈕尺寸與閱讀層級接近原型工具。

### P2：視覺完成度

- 全畫面以純黑背景、預設控制項與零散硬編碼顏色組成，缺乏一致的表面、邊框、焦點與狀態色。
- 地圖和結算內容只占畫面小區域，缺乏進度、圖例與結果層級。
- 沒有新遊戲、暫停、正式設定入口或共用音樂／音效管理介面。

## 本輪改造

- 建立資料化 `ui_theme.json`：統一背景、表面、邊框、文字、焦點、HP／Sanity／MP 狀態色、字級、間距、圓角與動效時間。
- 重組戰鬥畫面：盤面與手牌成為主要區域；敵人、玩家資源、遭遇資訊、支付預覽、結束回合與咒文圖例形成固定層級。
- 玩家 HUD 改用三條資源條；敵人卡加入 HP 條、意圖、狀態、護甲與目前目標標記。
- 手牌顯示 `1–3` 快捷鍵與名稱；鍵盤可用 `WASD` 移動、`Space` 放置、`X` 取消，非法位置以紅色預覽。拖曳仍完整保留。
- 遵守 `BOARD-005`，不提供手動旋轉；手牌方向仍由抽取流程決定。
- 地圖加入十層進度、節點圖例、路線 seed、節點圖標、可前往／完成狀態及初始焦點。
- 建立戰鬥外構築檢視，顯示咒文種類、份數、MP、稀有度、Tier、效果與方塊池。
- 獎勵改為同屏比較卡，直接顯示候選效果、MP、稀有度、Tier、持有份數與跳過收益。
- 事件、結算、主選單、暫停與設定畫面改用同一視覺規格；主要流程都有預設焦點。
- 建立 Music／SFX bus 與共用 `AudioManager`；正式音樂、音效及像素美術仍依資產里程碑逐步替換。
- 新增 UI 擷取工具，能固定輸出 title、map、battle、reward、settlement 狀態供視覺回歸。

## 保留邊界

目前構築畫面只提供檢視，不允許任意移除咒文或方塊。主動移除會直接改變抽取權重、獎勵價值與難度，因此以 `UX-007` 留待確認；現階段不自行新增這項規則。

英文 locale 已有設定與資料保存入口，但第一批完整英文字串表尚未製作；這不阻擋繁中內部原型的 Phase 17 操作驗收。

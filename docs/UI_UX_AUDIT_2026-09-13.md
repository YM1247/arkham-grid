# UI／操作體驗稽核（2026-09-13）

## 結論

改造前的介面已能驗證規則，但不適合連續遊玩：資訊主要堆在裸露文字與預設按鈕上，戰鬥畫面缺少清楚層級，地圖與結算有大量無效空白，而且拖曳幾乎是唯一盤面操作。Phase 17 本輪已將介面提升為可完整操作的第一版 PC 內部原型，建立統一 Theme、正式 HUD、畫面流程、焦點導覽及鍵盤放置。

## 改造前問題

### P0：直接影響操作

- 方塊只能依賴拖曳；沒有手牌選取、盤面游標、鍵盤放置或明確取消方式。
- 非法放置只讓預覽消失，玩家無法分辨越界、重疊或操作中斷。
- 地圖、獎勵與結算缺少一致的初始焦點，純鍵盤流程不完整。
- 戰鬥資訊散落在右側文字中，AP、時限、HP、Sanity、MP、狀態與敵人意圖無法快速掃讀。

### P1：資訊辨識與節奏

- 敵人資訊由總覽文字與敵人卡重複呈現，資訊擁擠但重點仍不突出。
- 玩家三種資源只有單行文字，難以辨識危險程度與變化。
- 手牌只有形狀，缺少名稱與快捷鍵提示；盤面列行以 `R1/C1` 呈現，增加不必要閱讀負擔。
- 獎勵候選只顯示名稱與 Tier，必須依賴 tooltip 才能比較效果與成本。
- 事件選項的代價、結果與不可選原因雖存在，但按鈕尺寸與閱讀層級接近原型工具。

### P2：視覺完成度

- 全畫面以純黑背景、預設控制項與零散硬編碼顏色組成，缺乏一致的表面、邊框、焦點與狀態色。
- 地圖和結算內容只占畫面小區域，缺乏進度、圖例與結果層級。
- 沒有新遊戲、暫停、正式設定入口或共用音樂／音效管理介面。

## 本輪改造

- 建立資料化 `ui_theme.json`：統一背景、表面、邊框、文字、焦點、HP／Sanity／MP 狀態色、字級、間距、圓角與動效時間。
- 重組戰鬥畫面：盤面與手牌成為主要區域；敵人、玩家資源、遭遇資訊、支付預覽、結束回合與咒文圖例形成固定層級。
- 玩家 HUD 改用三條資源條；敵人卡加入 HP 條、意圖、狀態、護甲與目前目標標記。
- 手牌顯示 `1–3` 快捷鍵與名稱；鍵盤可用 `WASD` 移動、`Space` 放置、`X` 取消，非法位置以紅色預覽。拖曳仍完整保留。
- 遵守 `BOARD-005`，不提供手動旋轉；手牌方向仍由抽取流程決定。
- 地圖加入十層進度、節點圖例、路線 seed、節點圖標、可前往／完成狀態及初始焦點。
- 建立戰鬥外構築檢視；Phase 17.1 已將其升級為完整石板卡，直接顯示形狀、效果格、咒文分類、MP 與效果。
- 獎勵改為同屏比較卡，直接顯示實際石板、候選效果、MP、稀有度與跳過收益；內部 Tier、形狀複雜度與格數不向玩家顯示。
- 事件、結算、主選單、暫停與設定畫面改用同一視覺規格；主要流程都有預設焦點。
- 建立 Music／SFX bus 與共用 `AudioManager`；Phase 17.1 已接入第一批正式像素角色與背景，音樂與音效仍待後續資產里程碑。
- 新增 UI 擷取工具，能固定輸出 title、map、battle、reward、settlement 狀態供視覺回歸。

## Phase 17.1 追補（2026-09-15）

- 咒文辨識改為七種大型分類符文；手牌常駐名稱、MP 與摘要，三個固定槽讓用牌後棋盤位置保持不變。
- 構築與獎勵直接顯示永久綁定的形狀、咒文及效果格，不再以形狀名稱或獨立咒文池代替實際抽牌內容。
- 加入原創像素調查員、六種敵人、三層儀式室與港城背景。戰鬥採玩家／棋盤／敵人三欄，最多五名敵人以 2×3 卡片陣列同屏顯示。
- 敵人依速度逐一播放蓄力、命中與返回；數值在命中節點才套用，左側保留最近四筆實際結果，玩家在演出期間不能操作盤面。
- 擷取器新增 build 模式與轉場完成等待；六個 1920×1080 基準畫面均完成視覺檢查。

## Phase 17.7 操作回饋追補（2026-09-16）

- 三張手牌的每一格使用相同縮放比例，不再因外框尺寸不同而忽大忽小；整張手牌提供放大的固定點選區，四格寬石板仍完整容納。
- 棋盤右側常駐消除預覽：拖曳或鍵盤移動時，依實際 Col → Row 順序列出所有會觸發的咒文、受狀態修正後的效果、MP 與 Sanity 代付總額。
- 咒文消除時先逐一彈出分類符文與名稱，該段演出完成後才結算各自效果；勝利結算延後到最後敵人的死亡淡出完成。
- Space 僅負責放置選中石板；結束回合按鈕不接受鍵盤焦點確認，鍵盤結束回合固定使用 Enter。
- 戰利品同屏顯示完整咒文資料與實際石板，不顯示形狀複雜度或格數；地圖與戰利品共用暗色像素框景。地圖只有已完成節點通往當前可選節點的連線會顯示金色。
- 刪除戰鬥 HUD 的「最近理智變化」欄位；MP 不足的 Sanity 代付只作為共通規則與消除預覽資訊，不再重複寫入每張咒文。

## Phase 17.8 資訊降噪追補（2026-09-16）

- 戰利品預覽的石板本體與咒文符文共用即時置中原點，任何形狀與卡片寬度下都保持效果格對齊。
- 手牌文字放大並擴寬；咒文的純敘事描述先從所有操作介面移除，只保留分類、MP、範圍與實際效果數值。
- 無咒文將觸發時不顯示「消除預覽」或操作附註；大量觸發內容限制於固定高度，不得撐動棋盤與回合按鈕。
- 護盾使用 HP 條上的白色輪廓段，MP 保持藍色填充，兩種資源不再依賴相同色彩辨識。

## 保留邊界

目前構築畫面只提供檢視，不允許任意移除石板。`UX-007` 已確認：一般介面不提供移除，只由商店每節點一次的付費服務及特定事件提供；實際移除服務仍屬後續內容工作。

英文 locale 已有設定與資料保存入口，但第一批完整英文字串表尚未製作；這不阻擋繁中內部原型的 Phase 17 操作驗收。

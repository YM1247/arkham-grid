# 遊戲體驗與平衡稽核（2026-09-08）

## 測試方法

本輪以 `tools/analyze_gameplay.gd` 重跑五組固定種子：`424242`、`13579`、`8675309`、`20260908`、`314159`。

- 每個種子執行 8 次完整 Run，共 40 Runs。
- 每個種子對六組 encounter 各執行 6 次獨立戰鬥，共 180 場。
- 每場上限 12 回合；代理會選擇目前評分最高的合法放置，因此結果代表「熟悉規則且近似最佳操作」的回歸基準，不等同真人勝率。
- 比較過四個版本：低傷害基準、提高傷害、提高攻擊意圖頻率，以及最後再延長敵人存活時間。

## 本輪已實作修正

1. MP 不足時不再讓咒文失效，改以相同數量的 Sanity 代付；戰鬥統計會獨立記錄代付次數。
2. 每種咒文都有自己的盤面圖標與分類色，手牌和落盤方塊不必等到游標移入才看得出效果類型。
3. 常規咒文不再提供直接治療或再生；原治療內容改為護甲與堅硬，HP 回復留給休息、商店與高代價節點。
4. 六名敵人的基礎攻擊調整為 `10/11/13/12/11/15`，重擊倍率為 1.5；攻擊型意圖比例提高，HP 調整為 `35/35/40/55/50/75`，讓意圖能在敵人被擊殺前形成壓力。

## 最終多種子結果

| 指標 | 結果 |
| --- | ---: |
| 完整 Run 通關率 | 85.0%（34/40） |
| HP／Sanity／超時失敗 | 4／2／0 |
| 平均結束 HP／Sanity／MP | 53.0／78.0／39.7 |
| 平均戰鬥勝場 | 5.65 |
| 平均特殊形狀取得 | 0.35／Run |
| 平均死盤 | 0.07／Run |
| 種子通關率範圍 | 75%–100% |

調整過程中，僅提高傷害仍是 40/40 通關；提高攻擊意圖頻率後也仍是 40/40。加入適度 HP、讓敵人多存活一至兩輪後，通關率才降至 85%。這表示先前「太簡單」的主因是敵人來不及執行足夠意圖，不只是面板傷害過低。

獨立 encounter 測試全部可通關，但資源消耗會隨進度提高：早期約 2.5–4.8 回合，後段約 5.5–7.0 回合；第五、六場部分種子的單場 Sanity 代付平均達 5–6 次。完整 Run 則會因跨場資源累積而產生 HP 與 Sanity 兩種失敗，符合雙壓力資源的設計。

## 現況判讀

### 難度平衡

- 近似最佳代理仍有 15% 失敗，真人在尚未熟悉圖標、咒文池與盤面規劃時預期會更難；現階段不應繼續全面加傷。
- 種子間有 75%–100% 的落差，代表路線、抽取和效果格位置仍會顯著影響難度。這是 Roguelike 所需變異，但滿勝率種子值得持續觀察。
- 死亡來源為 HP 4、Sanity 2，壓力不再只集中於單一資源。MP 代付解決無法行動的軟鎖，但也會在後段轉化為 Sanity 風險。

### 遊戲節奏

- 早期 2.5–4.8 回合能快速建立規則認知；後期 5.5–7.0 回合足以讓敵人意圖與狀態生效，曲線比先前更完整。
- 沒有任何 12 回合超時，代表提高 HP 尚未造成拖沓。
- 效果格自動觸發時，玩家可能在 MP 不足後連續支付多次 Sanity。機制已避免停擺，但 HUD 尚未在消除前清楚預告這次會用哪種資源支付。

### 豐富性

- 目前有 20 種咒文，但起始池只有 6 種不同咒文，且特殊形狀平均每 Run 僅取得 0.35 個；不少 Run 幾乎只在數值上成長，形狀構築的變化感偏弱。
- 敵人已有 8 種意圖，但本輪提高頻率後，`watch` 暫未被現行敵人使用；敵人差異主要來自攻擊順序、Sanity 攻擊與少數 buff／debuff。
- 每種咒文已有獨立圖標，可降低 hover 依賴；但玩家仍缺少常駐圖例與「這個符號代表什麼」的首次教學。

### 整體體驗

- MP 代付使玩家永遠能靠盤面繼續推進，優於咒文直接失效；代價則是低 Sanity 時可能因自動連鎖觸發意外死亡。
- 移除常規回血後，護甲、敵人意圖與節點回復的選擇更有意義，也避免以廉價回復抹平跨場壓力。
- 核心資訊已直接出現在方塊上，但圖標只解決辨識速度，尚未解決支付預覽和新手理解成本。

## 建議改變方案

### P0：下一輪優先

1. 在消除預覽中顯示預計觸發的咒文數量、總 MP 成本，以及不足部分會支付多少 Sanity；低 Sanity 可能致死時使用明顯警示。
2. 在戰鬥 HUD 加入可收合的咒文圖例，顯示圖標、名稱、效果與成本；首次遇到新圖標時給一次短提示。
3. 保留本輪敵人數值至少一輪真人測試。驗收目標：熟悉玩家完整 Run 通關率約 60%–80%，新玩家不因看不懂圖標或資源代付而失敗。

### P1：內容與節奏

1. 讓敵人依生命階段或玩家狀態切換意圖，而不是再提高基礎傷害；目標是增加可讀的決策，不增加無法預防的爆發。
2. 把現有 20 種咒文整理成 3–4 個可辨識流派，增加非治療型防禦與 MP／Sanity 風險交換，並檢查起始池不會長期只抽到同一功能。
3. 提高「至少看見一次特殊形狀獎勵」的可靠度，但不要直接提高星點石板抽牌權重；可改由獎勵候選保底處理。這會影響構築節奏，實作前需玩家確認。

### P2：持續觀測

1. 商店加入咒文、升級或特殊形狀商品，讓金錢除了補給外也能改變構築。
2. 擴充事件數量與敵人組合，避免六場路線重複體驗相同的意圖序列。
3. 持續追蹤以下自動基準：最佳代理通關率 70%–90%、超時低於 10%、後段 6–9 回合、HP 與 Sanity 都有失敗案例、第五／六場平均 Sanity 代付不高於每場 4 次。

## 需要玩家確認的方向

- 是否以獎勵候選保底，讓每個 Run 至少看見一次特殊形狀；這會提高形狀構築在整體玩法中的比重，已登錄為 `BOARD-007`。
- 是否讓敵人加入生命階段／條件式意圖；這會改變敵人設計規格與 UI 預告方式，已登錄為 `COMBAT-009`。

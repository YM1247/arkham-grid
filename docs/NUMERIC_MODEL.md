# 數值模型

## 核心基準

原型階段所有新內容先以短局快測為準。

| 項目 | 基準 |
| --- | --- |
| 玩家 HP | 80 |
| 玩家 Sanity | 70 / 100 |
| 玩家 AP | 5 |
| 普通戰鬥長度 | 2-4 玩家回合 |
| 普通敵人 HP | 30-60 |
| 普通敵人攻擊 | 8-12 |
| 每回合可期待護甲 | 8-18 |
| 無合法步懲罰 | -10 Sanity |
| 小型魔法成本 | 3 Sanity |

## 戰鬥長度估算

普通戰鬥的目標是 2-4 回合。估算方式：

```text
預期擊殺回合 = 敵人 HP / 每回合有效輸出
```

每回合有效輸出不是 AP 直接換算，而是取決於玩家能觸發幾條 Row / Col。原型階段用以下假設檢查：

- 低觸發回合：1 條線。
- 正常回合：1-2 條線。
- 高觸發回合：3 條以上或同時觸發 Row + Col。

若普通敵人 HP 為 30，則一個 20 傷害 Curse 加一個 10 傷害 Weapon 已可擊殺。這表示 HP 30 適合最早期測試，不適合作為長期普通敵人標準。

## 玩家資源

### HP

HP 是容錯資源，用來承接敵人攻擊與防禦失敗。

- 初始值：80。
- 普通敵人每回合攻擊：8-12。
- 若玩家完全不防禦，約 7-10 次普通攻擊死亡。
- 若玩家每回合能取得 8-18 護甲，普通攻擊應多數可被抵銷。

### Sanity

以下是目前 runtime 與既有批次基線使用的 Sanity 模型，並非下一版正式方向。`BALANCE-001` 已決定新增 MP 支付常規魔法，Sanity 改為特殊秘技與高代價內容；MP 上限、補充與不足處理須待 `MAGIC-001`，確認前保留本段數值以維持可比較基線。

- 初始值：70 / 100。
- 30 以下：理智不穩。
- 0：Run 失敗。
- 魔法 Col 成本：
  - 小型：3，適合普通高傷害或小 combo。
  - 中型：6，適合明顯高於同級的輸出或多重效果。
  - 大型：10，適合能扭轉局勢的強效果。
- 無合法步：-10，等同一次大型 Curse 的心理壓力。

## 道具強度

所有道具以 `balance_cost` 做內部估算。這不是玩家可見數值，而是設計時比較強度的粗略分數。

### 物理 Row：輸出

定位：穩定輸出，低副作用。

- Common：8-10 傷害，`balance_cost` 8-10。
- Uncommon：11-14 傷害，或小條件加成，`balance_cost` 11-15。
- Rare：15-20 傷害，或強條件加成，`balance_cost` 16-24。

### 物理 Row：防禦

定位：護甲、防禦轉換、生存。

- Common：10-12 護甲。
- Uncommon：13-18 護甲，或附帶小效果。
- Rare：18+ 護甲，或與 Row / Col / Sanity 互動。

### 魔法 Col：支援

定位：治療、穩定、修復 Sanity 或淨化負面狀態。

- Common：6-8 治療，或小護甲。
- Uncommon：9-12 治療，或治療加護甲。
- Rare：Sanity 修復、Curse 代價補償、低 Sanity 救場。
- 現行支援魔法也消耗 Sanity；改用 MP 後需重新驗證效率與資源循環。

### 魔法 Col：高風險輸出

定位：高效率、強連動、高風險。

下列仍是現行 Sanity 成本的歷史定價；MP 規則接線時需建立新基線後取代。

- 小型 Curse：成本 3，約 16-22 效益。
- 中型 Curse：成本 6，約 24-34 效益。
- 大型 Curse：成本 10，約 36+ 效益或強力 combo。

## Combo 定價

Combo 道具要先寫清楚觸發條件，再估算強度。

常見條件：

- 同時消除 Row + Col。
- 本回合已觸發 Curse。
- Sanity 低於 30。
- 清除指定類型區域，例如 Weapon Row 或 Curse Col。
- 使用特定形狀標籤的方塊，例如 `wide`、`tall`、`awkward`。

條件越難達成，可給越高倍率：

- 容易觸發：加成 20-30%。
- 中等觸發：加成 40-60%。
- 困難觸發：加成 80-120%。

## 效果範圍

範圍會大幅影響實戰價值，尤其在多敵人戰鬥中。

- 單體：基準倍率 1.0。
- 擴散：若預期命中 2-3 名敵人，單一目標數值應約為單體的 60-75%。
- 全體：若預期命中 3 名敵人，單一目標數值應約為單體的 40-60%。

Common 傷害基準：

- 單體 Weapon：8-10，帶副作用可到 15。
- 擴散 Weapon：6-8。
- 全體 Weapon：4-6。
- 單體 Curse：成本 3 時約 16-22 效益。
- 全體 Curse：成本 5-6 時，每名敵人約 3-6 效益，依持續傷害與回合數調整。

## 異常狀態

異常狀態同時適用於玩家與敵人。除非個別效果另有說明，可疊加狀態在該角色回合結束時 -1。

- 力量 X：攻擊傷害增加 X。
- 虛弱 X：攻擊傷害減少 X。
- 堅硬 X：獲得護盾增加 X。
- 脆弱 X：獲得護盾減少 X。
- 再生 X：回合結束時，回覆 X 點 HP。
- 中毒 X：回合結束時，受到 X 點傷害。

狀態的估值要看觸發者與目標：

- 給玩家的力量 / 堅硬通常可觸發多次收益，Common 建議 3-5。
- 給敵人的虛弱會降低未來傷害，Common 建議 3-5。
- 中毒若能持續 3 回合，中毒 5 的總期待傷害約為 12-15，適合成本 3 Curse。

## 敵人曲線

普通敵人以戰鬥序列逐步成長。

| 戰鬥序列 | HP | 攻擊 | 目標 |
| --- | --- | --- | --- |
| 1-2 | 30-45 | 8-10 | 熟悉節奏 |
| 3-5 | 45-70 | 10-14 | 需要穩定觸發裝備 |
| 6-8 | 70-100 | 14-18 | 檢查構築是否成形 |

若加入菁英敵人，建議 HP 為同階普通敵人的 1.5-2 倍，攻擊提高 20-40%。獎勵級別由關卡內所有敵人的 `tier` 統一計算。

目前多敵人 encounter 會讓總攻擊成長很快。若玩家沒有同步成長，難度會在中後段突然升高。成長應主要來自構築效率，而不是頻繁提高壓力資源上限或恢復壓力資源。

- 裝備替換品質提高：更高稀有度或更高 `balance_cost` 的獎勵逐步出現。
- 裝備升級：既有 slot 數值提升，而不是只替換橫向選項。
- 防禦穩定性提升：降低多敵人總攻擊造成的尖峰傷害。
- 特殊方塊 / 智慧手牌：提高玩家能觸發多條線的可靠度。

### 壓力資源成長限制

HP、Sanity 與 AP 是本遊戲的核心壓力來源，不應作為普通戰鬥三選一獎勵的常見成長。

- HP 回復 / 最大 HP 增加：非常稀有，應出現在休息、事件、Boss 後或高代價選擇。
- Sanity 回復 / 最大 Sanity 增加：非常稀有，且應比 HP 更受限制，避免抵銷 Prayer / Curse 與死盤懲罰的壓力。
- AP 上限增加：極高影響成長，會直接提高放置量、觸發頻率與智慧手牌價值；若出現，應屬於關鍵構築獎勵或重大代價，而非常規作戰收益。
- 普通戰鬥成長應優先給：特殊方塊、裝備替換、條件 combo、稀有度提升或手牌規則改變。

## 獎勵稀有度

- Common：穩定基礎效果，低條件。
- Uncommon：明確流派方向，或中等條件加成。
- Rare：強 combo、強 Curse、Sanity 互動、或能改變玩法的特殊方塊。

獎勵池應避免三個選項都服務同一功能。理想組合是：

- 1 個穩定即戰力。
- 1 個流派或 combo 選項。
- 1 個高風險高報酬選項。

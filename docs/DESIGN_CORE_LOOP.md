# 核心迴圈設計

## 目標體驗

Arkham Grid 的原型階段採用「短局快測」節奏。玩家應該能在數分鐘內完成數場戰鬥，快速看到方塊池、裝備配置、Sanity 壓力與獎勵選擇如何互相影響。

核心體驗是：在有限 AP 與有限棋盤空間中放置方塊，透過 Row / Col 消除觸發裝備，承受敵人攻擊與 Sanity 壓力，勝利後用三選一獎勵推動流派成形。

## 單場戰鬥節奏

- 預期長度：普通戰鬥 2-4 個玩家回合。
- 玩家基準：HP 80、Sanity 70/100、AP 5。
- 方塊成本：所有方塊放置固定消耗 1 AP。
- 盤面會跨戰鬥保留；下一場戰鬥只重置敵人、手牌、AP、護甲與暫時狀態。
- 回合結束時未使用手牌及方向會保留，下一回合只補足缺額。
- 開局與死盤懲罰後會生成一個接近可消除的友善盤面，避免玩家從完全空盤開始鋪太久。
- 敵人壓力：普通敵人每回合造成約 8-12 傷害。
- 防禦基準：玩家每回合透過 Equipment 可取得約 8-18 護甲。
- 戰鬥結束：
  - 敵人 HP 歸零：勝利，顯示三選一獎勵。
  - 玩家 HP 歸零：Run 失敗。
  - 玩家 Sanity 歸零：Run 失敗。

## 單局 Run 節奏

- 原型目標：一局 5-8 場戰鬥。
- 當前 v1：使用可重現的程序分層地圖，多起點與中段分支會匯聚到單一 Boss；每條完整路徑維持 5–8 場戰鬥。
- 節點節奏：
  - 普通戰鬥：主要內容與獎勵來源。
  - 菁英戰鬥：更高 HP / 攻擊 / Sanity 壓力，給較高稀有度獎勵。
  - 事件：以 Sanity 交易獎勵或資訊。
  - 休息：恢復 HP 或 Sanity，二選一形成取捨。
- 目前休息已接線；事件與商店仍是保留盤面後直接結束的佔位節點，尚未實作正式內容。

## 獎勵節奏

- 每場普通戰鬥勝利顯示 3 個選項。
- v1 獎勵類型：
  - 新增特殊方塊到方塊池；重複取得會增加池內份數與抽取權重。
  - 道具先放入背包，達條件時自動合成升級，再於戰鬥外比較並配置到合法 Row / Col 槽。
  - 可跳過三選一並換取局內金錢。
- 獎勵設計原則：
  - 早期獎勵應該讓玩家看見流派方向，而不是只給純數值升級。
  - 普通方塊屬於基礎方塊池，不作為戰鬥獎勵。
  - 方塊獎勵只保留給特殊方塊，負責改變「能不能觸發」或提供流派條件。
  - 道具獎勵改變「觸發後得到什麼」。
  - 常規戰鬥獎勵不提供 HP / Sanity 回復或上限增加，也不提供 AP 上限增加。
  - HP、Sanity 與 AP 成長屬於非常稀有的特殊獎勵，應保留給事件、菁英、Boss、關鍵節點或高代價選擇。
  - Curse 獎勵應該明顯強，但要讓 Sanity 成本成為真實風險。

## 多敵人戰鬥規劃

- 場上可以同時出現複數敵人。
- 玩家可以點擊敵人來鎖定目標。
- 戰鬥開始時預設鎖定第一名存活敵人；鎖定目標死亡後不自動重新鎖定，後續單體／擴散效果在玩家重新選擇前失效。
- 消除 Row / Col 後，道具效果會以鎖定目標為中心結算。
- 效果範圍分為三種：
  - 單體：只作用於鎖定目標。
  - 擴散：作用於鎖定目標與左右各一名敵人。
  - 全體：作用於所有存活敵人。
- 獎勵級別由關卡內所有敵人的 `tier` 統一計算，不由單一敵人掉落決定。

## Sanity 壓力

Sanity 是主要壓力來源，HP 是次要但仍可致死的戰鬥資源。

- Prayer / Curse 使用：
  - 小型成本：3。
  - 中型成本：6。
  - 大型成本：10。
- 無合法步懲罰：-10 Sanity，清空盤面並重抽手牌。
- 懲罰後盤面會重建為友善盤面，而不是完全空盤。
- 未來事件或特殊敵人：常用區間 -5 到 -15。
- 警戒線：
  - Sanity < 30：顯示「理智不穩」。
  - Sanity = 0：Run 失敗。
  - Sanity 45／25 為兩段門檻，會加入 1／2 個不重複的跨系統瘋狂效果；回復後會依門檻解除。

## Baseline 檢查

目前內容基準：

- 玩家：HP 80、Sanity 70/100、AP 5。
- 方塊：8 種普通方塊與 3 種特殊方塊。
- 道具：
  - Weapon：左輪手槍，10 傷害。
  - Equipment：防彈背心，15 護甲。
  - Prayer：聖光術，消耗 3 Sanity，10 治療。
  - Curse：暗影刺，20 傷害，Sanity 成本 3。
- 內容：20 件道具、6 種敵人、6 組遭遇與 20 項獎勵；普通敵人壓力仍以單回合 8–12 傷害為基準。
- 成長：普通勝利獎勵主要提供特殊方塊或裝備替換；HP / Sanity / AP 成長不屬於常規作戰獎勵。

此基準下，普通敵人應該在少量 Row / Col 觸發後死亡。若玩家能穩定 1 回合擊殺所有普通敵人，敵人 HP 或獎勵節奏需要上調；若常超過 4 回合，則方塊池或觸發頻率需要改善。

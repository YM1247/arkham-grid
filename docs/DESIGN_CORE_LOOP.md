# 核心迴圈設計

## 目標體驗

Arkham Grid 的原型階段採用「短局快測」節奏。玩家應該能在數分鐘內完成數場戰鬥，快速看到方塊形狀、咒文池、MP、Sanity 壓力與獎勵如何互相影響。

核心體驗是：在有限 AP 與棋盤空間中放置方塊，完成 Row／Col 並消除帶有獨立咒文圖標的效果格。玩家構築只需考慮方塊形狀與咒文池，不需記憶棋盤邊緣裝備。

## 單場戰鬥節奏

- 預期長度：早期普通戰鬥約 3–5 個玩家回合，後段約 5–7 回合。
- 玩家基準：HP 80、Sanity 70/100、MP 70/100、AP 5。
- 方塊成本：所有方塊放置固定消耗 1 AP。
- 盤面會跨戰鬥保留；下一場戰鬥只重置敵人、手牌、AP、護甲與暫時狀態。
- 回合結束時未使用手牌及方向會保留，下一回合只補足缺額。
- 開局與死盤懲罰後會生成一個接近可消除的友善盤面，避免玩家從完全空盤開始鋪太久。
- 每張方塊抽入手牌時，形狀、咒文與一個效果格獨立決定；同手在形狀種類足夠時不重複形狀。
- 被消除的每個效果格只觸發一次，即使同時位於 Row／Col 交會；MP 不足改用等量 Sanity 支付，咒文仍會觸發。
- 敵人壓力：基礎攻擊約 10–15，使用 8 種可預告意圖；攻擊／重擊形成主要壓力，防禦、凝神防備、精神侵蝕與強化／弱化建立節奏差異。
- 每場依敵人強度與節點深度設定 4–7 回合時限；逾時後每回合依序扣除 2、4、6… Sanity。
- 戰鬥結束：
  - 敵人 HP 歸零：勝利，顯示三選一獎勵。
  - 玩家 HP 歸零：Run 失敗。
  - 玩家 Sanity 歸零：Run 失敗。

## 單局 Run 節奏

- 原型目標：單章 10 層節點、約 7 場戰鬥。
- 當前 v1：使用可重現的 10 層程序分層地圖，多起點與中段分支會匯聚到單一 Boss；每條完整路徑固定經過 10 個節點。
- 節點節奏：
  - 普通戰鬥：主要內容與獎勵來源。
  - 菁英戰鬥：更高 HP / 攻擊 / Sanity 壓力，給較高稀有度獎勵。
  - 事件：以 Sanity 交易獎勵或資訊。
  - 休息：恢復 HP 或 Sanity，二選一形成取捨。
- 每完成一個節點固定回復 50 MP，最高不超過 100；不同職業可有不同初始 MP。
- 事件、商店與休息皆使用資料化選項介面，完成後保留盤面並套用固定節點 MP 回復。

## 獎勵節奏

- 每場普通戰鬥勝利顯示 3 個選項。
- v1 獎勵類型：
  - 解鎖一種低權重特殊形狀；同一形狀不重複取得。
  - 咒文直接加入咒文池；重複咒文會提高之後附著到方塊的機率。
  - 可跳過三選一並換取局內金錢。
- 獎勵設計原則：
  - 早期獎勵應該讓玩家看見流派方向，而不是只給純數值升級。
  - 普通方塊屬於基礎方塊池，不作為戰鬥獎勵。
  - 特殊形狀改變盤面解題方式，咒文改變效果格被消除後得到什麼。
  - 菁英獎勵候選保證至少一個尚未取得的特殊形狀，但不提高該形狀加入手牌後的抽取權重。
  - 常規戰鬥獎勵不提供 HP / Sanity 回復或上限增加，也不提供 AP 上限增加。
  - HP、Sanity 與 AP 成長屬於非常稀有的特殊獎勵，應保留給事件、菁英、Boss、關鍵節點或高代價選擇。

## 多敵人戰鬥規劃

- 場上可以同時出現複數敵人。
- 玩家可以點擊敵人來鎖定目標。
- 戰鬥開始時預設鎖定第一名存活敵人；鎖定目標死亡後，自動鎖定 encounter 原始順序中的第一名存活敵人。
- 消除 Row／Col 後，效果格上的咒文會以鎖定目標為中心結算。
- 效果範圍分為三種：
  - 單體：只作用於鎖定目標。
  - 擴散：作用於鎖定目標與左右各一名敵人。
  - 全體：作用於所有存活敵人。
- 獎勵級別由關卡內所有敵人的 `tier` 統一計算，不由單一敵人掉落決定。

## Sanity 壓力

HP、MP 與 Sanity 承擔不同壓力：HP 是持續生存資源，MP 是常規咒文燃料，Sanity 主要承擔戰鬥拖延，並在 MP 用盡時成為危險的備用燃料。

- 常規咒文成本約 2–8 MP；強化咒文可更高。
- MP 不足不會阻止行列消除；咒文以完整成本等量扣除 Sanity 後照常觸發。
- 無合法步懲罰：-10 Sanity，清空盤面並重抽手牌。
- 戰鬥超過時限：每個逾時回合依序 -2／-4／-6… Sanity；越深節點的時限越嚴格。
- 懲罰後盤面會重建為友善盤面，而不是完全空盤。
- 未來事件或特殊敵人：常用區間 -5 到 -15。
- 警戒線：
  - Sanity < 30：顯示「理智不穩」。
  - Sanity = 0：Run 失敗。
  - Sanity 45／25 為兩段門檻，會加入 1／2 個不重複的跨系統瘋狂效果；回復後會依門檻解除。

## Baseline 檢查

目前內容基準：

- 玩家：HP 80、Sanity 70/100、MP 70/100、AP 5；每完成節點回復 50 MP。
- 方塊：8 種普通方塊與 3 種特殊方塊。
- 咒文：20 種攻擊、防護與狀態咒文；常規咒文不提供直接治療或再生。
- 內容：6 種敵人、8 種意圖、8 組遭遇、2 個事件與 20 項獎勵；敵人基礎攻擊為 10–15。
- 成長：普通勝利獎勵主要提供咒文或特殊形狀；HP／Sanity／AP 成長不屬於常規作戰獎勵。

五組固定種子、40 次最佳策略代理測試的完整 Run 通關率為 77.5%，失敗包含 5 次 HP 與 4 次 Sanity 死亡，沒有 12 回合工具超時；平均每 Run 因戰鬥逾時損失 9.5 Sanity。這是自動回歸基準，不取代實際玩家手感測試。
